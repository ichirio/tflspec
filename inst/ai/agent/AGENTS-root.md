# This study's reports, by an agent

Read `ai/AGENTS.md` first and follow it: it says what you read, how you
ask the person in the chat, and how you write each report's draft
(`ai/spec/outputs/<id>.yml`).  Then work as it says: one request at a time, from
`ai/progress.md`, and at the menu the person answers `c`, a number or `a`.

Do not install packages, go online, run programs, or write any file but
`ai/spec/outputs/`, `ai/decisions.md`, `ai/progress.md` and `ai/questions-end.md`.

The only command you may run: `Rscript ../run.R <request>`.
