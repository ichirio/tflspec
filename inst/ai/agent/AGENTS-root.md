# This study's reports, by an agent

Read `ai/AGENTS.md` first and follow it: it says what you read, how you
ask the person in the chat, and how you write each report's draft
(`ai/spec/outputs/<id>.yml`).  Then do the requests of
`ai/requests/index.md` in order.  When the person says "continue", go on
from the first request with a draft missing.

Do not install packages, go online, run programs, or write any file but
`ai/spec/outputs/` and `ai/decisions.md`.
