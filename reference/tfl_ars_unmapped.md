# What the ARS does not say

What the ARS does not say

## Usage

``` r
tfl_ars_unmapped(ars)
```

## Arguments

- ars:

  A
  [`tfl_ars()`](https://ichirio.github.io/tflspec/reference/tfl_ars.md).

## Value

A data frame: `where` (the output / analysis or sheet), `item` (the spec
column) and `reason`.
