# Build a spec from data frames

Build a spec from data frames

## Usage

``` r
tfl_fig_spec(
  plots,
  roles = NULL,
  filters = NULL,
  levels = NULL,
  legend = NULL,
  options = NULL
)
```

## Arguments

- plots, roles, filters, levels, legend, options:

  Data frames with the columns of the corresponding spec sheet (missing
  columns are added).

## Value

A `tfl_fig_spec` object.
