# Read ADaM datasets

Read ADaM datasets

## Usage

``` r
tfl_read_adam(x)
```

## Arguments

- x:

  A folder containing `.xpt`, `.sas7bdat`, `.rds` or `.rda` (`.RData`,
  one dataset a file) files, or a named list of data frames.

## Value

A named list of data frames; names are upper-case dataset names.
